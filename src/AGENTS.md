
# SRC (SOURCE) of the QUANTUM GRAVITY ENGINE

Contains:
 - *`./bin/`*: Rust-Executables (Stand-alones) for the Quantum Gravity Engine.
 - *`./core/`*: Core Library for the Quantum Gravity Engine.
 - *`./math/`*: Mathematical Library for the Quantum Gravity Engine.
 - *`./misc/`*: Miscellaneous Library for the Quantum Gravity Engine.
 - *`./util/`*: Utilities Library for the Quantum Gravity Engine.
 - *`./follow/`*: Follow™-Frameworks Library for the Quantum Gravity Engine.
 - *`./io/`*: IO-Layer (Memory Offloading, Files, etc.) Library for the Quantum Gravity Engine.
 - *`./quantum/`*: Quantum Gravity Library for the Quantum Gravity Engine.
 - *`./everything/`*: Theory of Everything Library for the Quantum Gravity Engine.
